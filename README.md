# MariAo: A Stray Cat Rescue Website 

This is a static website project built to support stray cat rescue efforts at my university. The site tells the stories of rescued cats, shares their growth, collects donations, and allows visitors to leave messages of support. It was created from HTML, CSS, and JavaScript.

## Website
Visit the live site here: [https://marioandaowu.netlify.app](https://marioandaowu.netlify.app)

## Features

- **Cat Profiles**: Stories and photos of rescued cats
- **Growth Records**: Track the cats' development over time
- **Donation Info**: Share how to support their care
- **Letter Board**: Visitors can write public or private messages to the cats
- **Clean Navigation**: Reusable navigation and footer for all pages
- **Frontend Only**: Built without a backend, content is stored directly in HTML

## Tech Stack

- HTML, CSS, JavaScript
- jQuery for simplified DOM manipulation
- Baidu Analytics for basic traffic tracking
- Netlify for deployment


## Motivation

During university, I helped rescue stray cats and wanted to support them more. This website was my way of sharing their stories and inviting people to help. I had never used frontend languages before, so I learned everything from scratch and completed the project alone. It was a lot of work, but very meaningful. I'm proud that it helped both the animals and the community.
